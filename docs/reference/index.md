# Package index

## All functions

- [`ebdt()`](https://migmontal.github.io/ebdt/reference/ebdt.md) :
  Calculate all parameters of a binary diagnostic test in a traverse or
  Cross-sectional study.
- [`ebdt_kap()`](https://migmontal.github.io/ebdt/reference/ebdt_kap.md)
  : Calculate the weighted Kappa coefficient
- [`ebdt_nlr()`](https://migmontal.github.io/ebdt/reference/ebdt_nlr.md)
  : Calculates the Negative likelihood ratio
- [`ebdt_npv()`](https://migmontal.github.io/ebdt/reference/ebdt_npv.md)
  : Calculates the Negative Predictive Value (only Cross-sectional
  study)
- [`ebdt_plr()`](https://migmontal.github.io/ebdt/reference/ebdt_plr.md)
  : Calculates the Positive likelihood ratio
- [`ebdt_ppv()`](https://migmontal.github.io/ebdt/reference/ebdt_ppv.md)
  : Calculates the Positive Predictive Value (only Cross-sectional
  study)
- [`ebdt_prev()`](https://migmontal.github.io/ebdt/reference/ebdt_prev.md)
  : Calculate Prevalence (only Cross-sectional study)
- [`ebdt_se()`](https://migmontal.github.io/ebdt/reference/ebdt_se.md) :
  Calculate Sensitivity
- [`ebdt_sp()`](https://migmontal.github.io/ebdt/reference/ebdt_sp.md) :
  Calculate Specificity
- [`ebdt_you()`](https://migmontal.github.io/ebdt/reference/ebdt_you.md)
  : Calculate Youden index
- [`gn_nlr()`](https://migmontal.github.io/ebdt/reference/gn_nlr.md) :
  Calculate Gart-Nam CI for negative likelihood ratio
- [`gn_plr()`](https://migmontal.github.io/ebdt/reference/gn_plr.md) :
  Calculate Gart-Nam CI for positive likelihood ratio
